# ФМиМРАЗ

Скрипты решают учебные задачи по принятию решений/экспертным оценкам и демонстрируют расчеты в GUI ('zenity') или в консоли (stdout).

## Требования
- Linux + Bash 4+.
- Утилиты: 'bc' (вычисления) и 'zenity' (GUI).
- Если чего-то нет, скрипты подскажут команды установки ('sudo apt install zenity' / 'sudo apt install bc').

## Запуск
1) Перед запуском, сделайте файлы исполняемыми:  
'chmod +x TASK1.sh TASK2.sh TASK3.sh TASK4.sh TASK5.sh'

> Альтернатива: можно запускать через файловый менеджер (например, "Открыть с помощью…" → "Использовать команду" → 'bash').  
> Однако рекомендуется запуск из терминала, чтобы видеть сообщения об ошибках.

2) Запуск с GUI-меню (из каталога со скриптом):  
'./ИМЯ_СКРИПТА.sh' — точка перед наименованиями обязательна для запуска исполняемых файлов в терминале.

3) Запуск с выводом результатов вычислений в stdout:  
'./ИМЯ_СКРИПТА.sh calc'

## Менеджер данных
- При старте загружается шаблон данных "по умолчанию" ('DEFAULT_TEMPLATE'), поэтому скрипты работают сразу.
- Чтобы подставить свои данные: в меню выберите **«Редактировать данные»** и измените шаблон.
- После сохранения скрипт валидирует ввод и пересчитывает все с новыми данными; при ошибках покажет сообщения и не применит некорректный шаблон.

## Что делают скрипты
- 'TASK1.sh' — экспертные оценки: агрегация, парные сравнения, веса критериев, согласованность, корреляция ранжировок.
- 'TASK2.sh' — принятие решений при определенности: нормализация, принципы оптимальности (в т.ч. Парето, "идеальная точка"/TOPSIS и др.).
- 'TASK3.sh' — однокритериальный выбор при неопределенности/риске: известное состояние, EMV (при вероятностях), Вальд/Лаплас/Сэвидж/Гурвиц и выводы.
- 'TASK4.sh' — многокритериальный выбор при неопределенности: 3D-данные (альтернатива×состояние×критерий) → интегральная матрица → анализ определенности/риска/неопределенности.
- 'TASK5.sh' — выбор на основе нечетких множеств/нечеткого вывода (ввод термов, правил и расчет результата).

## Быстрый сценарий
Запустить нужный скрипт → (опционально) «Условия задачи» → «Редактировать данные» → «Выполнить все задачи» → анализ полученных результатов.
